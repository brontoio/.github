# Support

Thanks for using Bronto! Here is how to get help with our open source projects.

## Documentation

The Bronto documentation is the best place to start:

- 📚 Docs: https://docs.bronto.io/welcome
- 🌐 Website: https://bronto.io

## Questions and Help

- **Bug reports and feature requests:** open an issue in the relevant repository
  and pick the appropriate template.
- **Usage questions and ideas:** open an issue using the question template, or
  start a discussion if the repository has GitHub Discussions enabled.

When opening an issue, please include your environment details and clear steps to
reproduce — it helps us help you faster.

## Commercial Support

If you are a Bronto customer and need help with your account, the platform, or a
production incident, please use the support channels available in the
[Bronto app](https://app.eu.bronto.io) or contact your account team.

## Security

Please **do not** open public issues for security problems. See
[SECURITY.md](SECURITY.md) for how to report vulnerabilities responsibly.
